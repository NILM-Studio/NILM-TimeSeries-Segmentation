## 数据流解析


### 1. 单次工作数据提取

在NILM数据集中，会记录一段总干线和各个用电器的工作数据。每个用电器的工作数据包含时间戳、功率等信息，其中包括了大量用电器处于OFF状态的数据，我们仅需要提取出用电器工作时的数据。Claspy项目可以提取每个用电器的工作数据，将其转换为csv格式。

输入：用电器工作数据，例如UK-DALE中的channel1.dat文件

输出：一个以Appliance Name命名的文件夹，文件夹中包含以csv格式存储的单次工作数据，每个csv文件对应一个用电器的工作数据。
命名格式：

Appliance_Name_Start_Time_End_Time_Duration.csv

例如：

Dishwasher_20121110_073803_20121110_075628_162s.csv

源码：
[Claspy项目](https://github.com/NILM-Studio/claspy)下的extract_active_data.py脚本

### 2. 语义分割

用电器单次工作数据可以包含多个基元状态，我们使用语义分割将一段单次工作数据切分为多个基元状态。

#### 实现原理

语义分割基于小波变换和 ClaSP（Change Point Detection）算法，主要步骤如下：

1. **信号预处理**：对输入的功率信号进行中值滤波去噪，去除异常值
2. **小波分解**：使用离散小波变换（DWT）将信号分解为低频和高频分量
3. **分割检测**：对低频和高频分量分别使用 ClaSP 算法检测分割点
4. **分割点融合**：将高低频分量的分割点进行融合，得到最终的语义分割结果
5. **结果输出**：将分割后的信号和分割点信息保存为CSV文件

#### 输入输出

**输入**：用电器单次工作数据（CSV格式），包含时间戳和功率值

**输出**：
- 分割后的信号数据（保存到 `data/` 目录）
- 分割点信息（保存到 `label/` 目录）
- 归一化参数（保存到 `norm_params/` 目录）
- 可视化结果（可选，保存为PNG文件）

#### 源码

`https://github.com/NILM-Studio/claspy` 下的 `wavelet_clasp_segmentation/wavelet_separation.py` 脚本

#### 技术特点

1. **多尺度分析**：通过小波变换分解信号，同时考虑低频和高频特征
2. **自适应分割**：使用 ClaSP 算法自动检测分割点，无需手动设置阈值
3. **鲁棒性**：通过中值滤波和归一化处理，提高分割的准确性
4. **可解释性**：生成详细的分割点信息和可视化结果，便于分析和调试
5. **灵活配置**：支持多种距离度量方法和验证策略，适应不同类型的用电器数据

#### 示例输出

分割点信息示例（Changepoints_*.csv）：

| timestamp | power | datetime | changepoint_index | label_type |
|----------|-------|----------|------------------|-----------|
| 1352504283 | 120.5 | 2012-11-10 07:38:03 | 128 | 0 |
| 1352505028 | 85.2 | 2012-11-10 07:50:28 | 356 | 0 |
| 1352505388 | 15.7 | 2012-11-10 07:56:28 | 462 | 0 |

其中 label_type=0 表示合成分割点，label_type=1 表示低频分量分割点，label_type=2 表示高频分量分割点。


### 3. 基元状态分类

#### 3.1 数据准备

流程2中输出的分割点和活动数据是分离的，不便于后续进一步处理，因此需要进一步处理。本步骤使用 `timeseries_clustering.py` 脚本将分离的数据进行整合、切割和标准化，为后续的聚类分析做准备。

##### 功能说明
- **数据匹配**：将活动数据文件与对应的分割点文件进行匹配
- **数据切割**：根据分割点将单次工作数据切分为多个基元状态段
- **数据标准化**：将不同长度的数据段填充为相同长度，便于后续聚类处理
- **特征提取**：支持提取多个特征列（如功率、清洗功率、高频分量、低频分量等）

##### 核心流程
1. **匹配数据文件**：遍历活动数据文件夹，为每个文件匹配对应的分割点文件
2. **过滤分割点**：根据需要选择不同类型的分割点（融合/低频/高频）
3. **切割数据段**：根据分割点时间戳将数据切分为多个段
4. **数据标准化**：计算最大长度，对所有数据段进行填充
5. **特征提取**：提取指定的特征列数据
6. **结果保存**：将处理后的数据保存为numpy数组和JSON文件

##### 输入输出

**输入**：
- 活动数据文件（`clasp_seg/{Appliance_Name}/data/` 目录下的CSV文件）
- 分割点文件（`clasp_seg/{Appliance_Name}/fluss_label/` 目录下的CSV文件）

**输出**：
- `cluster_data/{Appliance_Name}/fluss_data/` 目录下的文件：
  - `data_{label_type}.npy`：填充后的特征数据（形状：[样本数, 最大长度, 特征维度]）
  - `seq_length_{label_type}.npy`：每个数据段的原始长度
  - `data_mapping_list_{label_type}.json`：数据段的元信息映射

##### 配置参数
- `APPLIANCE_NAME`：电器类型（如 'washing_machine'）
- `DATA_COLUMN`：要提取的特征列（如 ['timestamp', 'power', 'cleaned_power', 'high_freq', 'low_freq']）
- `LABEL_TYPE`：分割点类型（-1: 所有, 0: 融合, 1: 低频, 2: 高频）

##### 技术特点
1. **模块化设计**：核心功能拆分为独立函数，便于维护和扩展
2. **灵活配置**：支持多种特征提取和分割点类型选择
3. **数据可视化**：内置数据段可视化功能，便于分析数据质量
4. **详细统计**：提供数据处理的详细统计信息，便于评估处理效果
5. **错误处理**：包含基本的异常捕获和提示，提高脚本的鲁棒性

##### 运行示例
```bash
# 在 time_clustering 目录下运行
python timeseries_clustering.py
```

运行后会生成处理后的数据文件，为后续的基元状态分类做准备。
